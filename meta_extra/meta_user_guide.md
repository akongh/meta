# Руководство Меты

*Руководство в состоянии составления*

Руководство по использованию Меты — сервиса русско-английского подбора
ключевых слов для стоков.

**Мета** (*русск. — метка, пометка, знак*) — сервис русско-английского подбора ключевых слов для стоковых произведений. Создан специально для русскоговорящих авторов, которым думать и подбирать ключевые слова на русском языке удобнее чем на английском.

## Определения

**Ключевое слово** — одно или несколько связанных между собой слов, передающих неделимый смысл.

Например, ключевыми словами являются как слова *семья*, *радость* и *природа*, так и словосочетания *день победы*, *георгий победоносец* и *божья коровка*. Здесь словосочетания несут неделимый смысл, поэтому их на *день* и *победа*, *георгий* и *победоносец*, *божья* и *коровка* разделить без потери исходного смысла нельзя.

А вот, например, словосочетания *красивая улыбка*, *успешный бизнесмен* и *чашка кофе на столе* не являются ключевыми словами и их следует разделять на *красивая* и *улыбка*, *успешный* и *бизнесмен*, *чашка*, *кофе* и *стол*.

В общем случае словосочетания могут быть ключевыми словами, если являются различными официальными названиями, именами собственными и т. п.

В спорных случаях судьба словосочетания решается администраторами Меты.

**Опорные ключевые слова** — частный случай ключевых слов, когда они задаются пользователем и используются Метой для поиска подходящих им других ключевых слов.

**Запрос** — одно и более опорное ключевое слово, задаваемое Мете для поиска подходящих им других ключевых слов за раз. Запрос состоит из опорных ключевых слов.

**Набор** — определённое количество ключевых слов, относящихся к одному конкретному произведению. Мета в итоге создаёт два варианта одного набора: первый на русском языке и второй на английском.

**Подбор** — результат поиска подходящих ключевых слов по запросу или определённая законченная последовательность действий при помощи Меты в целом для создания набора.

**Составной подбор** — частный случай подбора, когда для получения набора часть определённой законченной последовательности действий при помощи Меты производится несколько раз, получая промежуточные результаты подбора из которых в итоге формируется окончательный набор.

## Возможности

Думайте и подбирайте ключевые слова к своим произведениям (фотографиям, иллюстрациям, футажам…) на русском и получайте результат с переводом на английский.

Никакой кривой автоматики, каждое ключевое слово переведено вручную с учётом языковых особенностей.

**Управляйте** точностью подбора, делая запрос по одному или нескольким опорным ключевым словам.

**Выбирайте** подходящие ключевые слова в результате текущего подбора.

**Добавляйте** свои ключевые слова, если их нет в результате текущего подбора.

**Возвращайтесь**, чтобы уточнить последний запрос или изменить последний подбор.

**Запоминайте** текущий результат, чтобы дополнить его новым подбором.

**Формируйте** результат из неограниченного числа подборов.

**Забудьте** о дубликатах — они удаляются автоматически.

**Очищайте** перед переводом накопленный результат в удобном промежуточном списке с алфавитным порядком.

**Задавайте** очерёдность подобранным ключевым словам просто перетаскивая их.

**Выбирайте** для каждого ключевого слова подходящий перевод из предложенных.

**Получайте** в итоге два списка ключевых слов: на русском и английском языках.

## Правила

- Опорные ключевые слова должны быть только на **русском языке**.
- В опорных ключевых словах допустимы только **кириллица**, **цифры**, **пробел** и **дефис**.
- **е** ≠ **ё**
- Разделяйте опорные ключевые слова **переносами строк**, **запятыми**, **точками с запятыми**.
-обел не является разделителем, т. к. ключевым словом может быть словосочетание, например, *день святого валентина*.
- Нельзя создать набор, содержащий *менее 8-ми* ключевых слов.
- Есть вероятность отсутствия **результата** подбора. Возможные причины:
  - настройка условий подбора;
  - слишком много опорных ключевых слов;
  - ошибка в опорных ключевых словах;
  - неизвестные для Меты опорные ключевые слова.
- Есть вероятность отсутствия **перевода* ключевого слова. В таком случае, если набор с этим ключевым словом создаётся, то оно попадает в очередь на перевод.

## Описание шагов создания набора

Весь путь создания набора с помощью Меты состоит из **6-ти** последовательных шагов, **первые 3** из которых в пределах создания одного набора можно повторять по кругу необходимое число раз, если производится составной подбор.

### Шаг 1

- Задаются опорные ключевые слова.
- Выбирается число ключевых слов в результате подбора. Данная возможность предназначена для экономии времени на просмотре результата подбора на 2-ом шаге, если тема произведения достаточно узка или конкретна — скорее всего достаточно будет выбора меньшего числа ключевых слов в результате подбора. В противном случае лучше подойдёт большее число ключевых слов.
- Определяется способ поиска: по бо́льшему числу совпадений или нет. Это условие себя проявляет только при количестве опорных ключевых слов от двух и более. Предназначено для повышения вероятности результата подбора за счёт точности.
- Возможность полного сброса текущего подбора.
- Отображение текущего состояния набора, если производится составной подбор.

**[?]**
```
[1] Опорные ключевые слова могут быть только на русском языке.
[2] Допустимы только кириллица, цифры, пробел и дефис.
[3] «е» ≠ «ё».
[4] Ключевыми словами могут быть словосочетания, например, имена собственные (названия праздников, населённых пунктов, организаций и т. п.), а также некоторые другие неделимые по смыслу словосочетания (в полный рост, 5 лет и т. д.).
[5] Словосочетания типа «красный бант», «многолюдная улица» и т. п. не являются неделимыми по смыслу, так как каждая их часть имеет смысл по отдельности, поэтому их следует разделять.
[6] Для разделения опорных ключевых слов следует использовать переносы строк, запятые, точки с запятыми.
[7] Флаг «Не строго»  предназначен для повышения вероятности результата подбора за счёт точности.
[8] Флаг  «Не более 80/160» определяет  число ключевых слов в результате подбора на 2-м шаге.
```


### Шаг 2

- Списком отображается результат подбора в порядке убывания по частоте встречания среди подходящих ключевых слов.
- Возможность добавления своих ключевых слов, если таковых не хватает в результате подбора.
- Возможность задания алфавитного порядка в списке выбранных ключевых слов для 3-го шага. Алфавитный порядок списка на третьем шаге сделает удобным окончательный отсев среди похожих слов. Зато текущий порядок может оказаться более подходящим при определении очерёдности на 4-м шаге, чем сэкономит время.
- Возможность возврата на 1-й шаг для уточнения опорных ключевых слов.
- Возможность полного сброса текущего подбора.

**[?]**
```
[1] Для выбора/отмены выбора ключевого слова можно нажать в любое место выделенной под курсором строки.
[2] При добавлении своих ключевых слов действуют те же правила, что и на 1-м шаге.
[3] Флаг «Алфавитный порядок» делает иногда более удобным отсев излишних похожих ключевых слов из подбора на 3-м шаге.
```

### Шаг 3

- Получаем текущий результат списком и можем ещё раз окончательно отсеять ненужные ключевые слова. Особенно удобно при составных подборах.
- Возможность задания для 4-го шага очерёдности ключевых слов в получившемся списке по частоте в базе Меты. Частота в базе Меты приблизительно отражает популярность того или иного ключевого слова среди авторов, использующих Мету и может сэкономить время при задании очерёдности на 4-ом шаге за счёт точности очерёдности. При этом возможность ручной правки очерёдности на 4-м шаге сохраняется.
- Возможность запомнить текущий результат подбора и вернуться на 1-й шаг для нового дополнительного запроса, делая таким образом составной подбор. Если до этого уже был сохранён предыдущий результат, текущее сохранение дополнит его.
- Возможность возврата на 2-й шаг для изменения текущего подбора и уточнения дополнительных ключевых слов.
- Возможность возврата на 1-й шаг для уточнения опорных ключевых слов.
- Возможность полного сброса текущего подбора.

**[?]**
```
[1] Для выбора/отмены выбора ключевого слова можно нажать в любое место выделенной под курсором строки.
[2] Счётчик внизу подбора показывает текущее количество выбранных ключевых слов.
[3] Переход на 4-й шаг невозможен, если выбрано менее 8-ми ключевых слов.
[4] Флаг «По частоте в  Мете» позволяет выставить очерёдность слов на 4-м шаге по популярности среди авторов, использующих Мету.
```

### Шаг 4

- Перетаскиванием создаём необходимую очерёдность ключевых слов. Очерёдность важна для некоторых стоков.
- Возможность полного сброса текущего подбора.

**[?]**
```
[1] Перемещение ключевых слов возможно из любого места выделенной под курсором строки, при этом курсор принимает вид крестика их двунаправленных стрелок.
```

### Шаг 5

- Выбираем подходящий перевод для каждого ключевого слова.
- Возможность полного сброса текущего подбора.

**[?]**
```
[1] Для выбора/отмены выбора перевода ключевого слова можно нажать в любом месте выделенной под курсором строки.
[2] При отсутствии выбора хотя бы одного перевода блок ключевого слово с переводом (-ми)  выделяется цветом для наглядности.
[3] Отметка «в заявке на перевод» означает, что для данного ключевого слова перевода в данный момент нет, но оно будет рассмотрено и переведено либо откорректировано и переведено. Список ключевых слов в заявке можно посмотреть на странице «Очередь на перевод».
[4] Счётчик внизу набора показывает текущее количество выбранных русских/английских ключевых слов в наборе.
```

### Шаг 6

- Получаем готовый набор в виде двух списков ключевых слов: на русском и на английском. Количество слов в списках может отличаться, т. к. для одного ключевого слова на русском языке может быть выбрано несколько переводов на английский либо есть дубликаты среди выбранных ключевых слов на английском языке, которые автоматически удаляются.

**[?]**
```
[1] Нажатие кнопки «Изменить вид на единый» объединяет ключевые слова на русском и на английском языках в единый блок, нажатие кнопки «Изменить вид на раздельный» разделяет блок перевода на два отдельных языковых блока, соответственно. 
[2] При наведении курсора и нажатии на блок ключевых слов ключевые слова выделяются для удобства их копирования.
```
